super-beautiful-modals

Same library, called from a click handler. The host mounts itself. The normal Angular path is a component inside the dialog.

From a click

Pass event.currentTarget, not event.target. A click on an icon inside the button would otherwise morph the icon. 

const ok = await modal.open({
    origin: event.currentTarget as HTMLElement,
    title: 'Delete this movement?',
    variant: 'danger',
})

From a template ref

Same call, when the opener is not the click target. #opener is an HTMLElement. Keep it in the DOM until close. 

<button #opener (click)="onOpen(opener)">Open</button>

onOpen(origin: HTMLElement) {
    return modal.open({ origin, title: 'Hello' })
}

Confirm

The default card is a title, a description and two actions. Confirm resolves true, cancel false, Escape or overlay undefined. After await, write a signal — this app is zoneless.

{{ lastResult() }}

An Angular component inside

This is the normal Angular path. Put the createComponent bridge on an injectable once, then every dialog is a component and a click. 

const name = await this.modal.openComponent(PlaylistForm, {
    origin: event.currentTarget as HTMLElement,
})

Nested

A dialog can open another. The one underneath scales back and goes inert until the top one leaves. The inner confirm morphs out of the Angular button.
